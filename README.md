# About Me

전기·반도체 전공을 기반으로 IoT 시스템 개발을 학습하고 있습니다.

Raspberry Pi와 Arduino를 활용한 장치 제어부터 MQTT·Serial 통신,
데이터베이스, 모니터링 애플리케이션까지 시스템의 전체 흐름을 구현해 왔습니다.

최근에는 YOLO 기반 객체 인식 등 AI 기술을 기존 시스템과 연동하며
IoT·임베디드 시스템의 개발 범위를 확장하고 있습니다.
